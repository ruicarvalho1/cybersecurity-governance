# Cybersecurity Governance & Risk

A collection of practical cybersecurity labs developed during my Master's in Cybersecurity at the University of Minho.

This repository documents hands-on work across different areas of cybersecurity management, governance, risk assessment, security engineering and technical security analysis.

## Overview

The practical exercises explore how cybersecurity principles can be applied to real-world organizational and technical scenarios.

Topics covered throughout the labs include:

* Cybersecurity governance
* Information security policies
* Risk identification and assessment
* Security controls
* Security requirements
* Compliance and regulatory considerations
* Security engineering
* Threat and vulnerability analysis
* Incident management
* Access control
* Offensive security concepts

## Main Areas

### Governance & Security Policies

Development and analysis of information security policies, security responsibilities, access control mechanisms and organizational security requirements.

### Risk Management

Identification of critical information assets, threats, vulnerabilities and potential impacts, followed by risk assessment and mitigation considerations.

### Security Engineering

Application of structured security engineering concepts and frameworks to evaluate security processes, requirements and organizational capabilities.

### Security Analysis

Practical analysis of security problems and vulnerabilities, combining theoretical concepts with hands-on exercises.
